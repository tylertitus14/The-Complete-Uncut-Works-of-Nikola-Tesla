1. Introduction and The Rise-Over-Run Metric Space
The traditional Collatz function T(x) over all positive integers is defined over a piecewise domain:
If x is even: T(x) = x / 2
If x is odd: T(x) = 3x + 1

L(x) = floor( log2(x) ) + 1
Under this transformation, the system's operations are decoupled from raw magnitude changes and translated into a localized string-length displacement metric—a geometric Rise-over-Run:
•	The Run Step (Even Division): When x is even, dividing by 2 equates to a right bit-shift (x >> 1), which truncates the trailing bit. This yields an exact, invariant string length displacement of:
Delta_L_Run = -1.0 bit
•	The Rise Step (Odd Expansion): When x is odd, the transformation 3x+1 can be expressed as (2x + x) + 1. In binary, 2x is a left bit-shift (x << 1). The addition of the original string scales the number up by a maximum factor of log2(3). This yields a maximum string length displacement of:
Delta_L_Rise approx. +2.0 bits
Because Delta_L_Rise > |Delta_L_Run|, a single isolated odd step expands the string faster than a single even step can truncate it. The core problem of the conjecture reduces to proving that the sequence cannot systematically exploit this geometric advantage to achieve infinite string growth or isolate itself in an unproved closed loop.
